What is the Bootflow? Platform SDK

All four Fortis Unity games share the same underlying Platform SDK BootflowSequence from cen-sdks. This is a sequential initialization pipeline that handles authentication, geo-fencing, age gate, terms of service, consent, and attribution — in a region-aware order. Mergemon (web) uses the TypeScript equivalent @fortis/sdk.

💡
Each game plugs into the same SDK bootflow but customizes it: different UI prefabs, different ToS URLs, different DI frameworks, different compliance configurations. The tabs above show each game's exact sequence.
Master Bootflow Order (Platform SDK)
🔑
Account Init + Authentication Always
Restore previous Terra/Sol auth, native recovery (Game Center / Play Games), or silently create a guest account. No UI shown.
📡
Analytics Init Always
Initialize analytics pipeline, install tracking, start analytics session. No UI shown.
🚫
Region Blocked Dialog If geo-fenced
GeoFencingStep checks if the player's country is allowed. If blocked — shows a full-screen blocked dialog and halts the game.
📋
Terms of Service + Privacy Policy Always (first launch)
TosPrivacyAgeGateStep → shows ToS and Privacy Policy agreement. Separate or combined with Age Gate depending on game config.
🎂
Age Gate If region requires it
Age slider (0–65+). Player must enter their age. If underage → AgeBlocked result, game halts. Some games merge this with ToS into a single combined dialog.
🍪
OneTrust Consent Banner EU / GDPR regions
DataConsentStep shows the OneTrust consent banner. Only shown if ShouldShowBanner is true (driven by compliance flow: Explicit or Default). Implicit flow records consent silently.
📱
iOS App Tracking Transparency iOS only + trackers permitted
Native iOS system prompt. Only shown if status is notDetermined and the age gate result grants trackers permission.
🔔
Push Primer If registered
BootflowRuntimeSteps plug-and-play step. Prompts the player to allow push notifications before the native OS dialog fires. Not all games use this.

Demeter Unity · VContainer

Entry point: GuestLoginManager.LogIn() → AgeGateAndTermsOfServiceManager.ShowAgeGateAndTerms() → WhitelabelBootflowManager.CheckAgeGateAndTermsAndConditions() → _bootflowSequence.Run()

⚙️
Config: UseCombinedAgeGate is configurable — either a single Combined AgeGate+ToS dialog, or two separate screens. PlatformBootflowConfiguration.asset controls which prefab is used.
Modal Sequence
🚫
Region Blocked Dialog Blocks game
Full-screen overlay via RegionBlockedDialog. No retry — game halts if region is geo-fenced.
📋
ToS + Privacy Policy Always · first launch
Shown separately (when UseCombinedAgeGate=false) — or merged with Age Gate into a single dialog.
🎂
Age Gate / Combined Dialog If AgeGateRule = Required
DemeterCombinedAgeGateDialog prefab with age slider (0–65+). When combined, shows ToS + Age slider in one screen with Unity slider widget (CombinedAgeGateDialogHelper.cs).
🔞
Age Blocked Screen If underage
If canPlay = false — bootflow result is ageBlocked. Game does not proceed.
🍪
OneTrust Consent Banner EU / GDPR only
Custom Unity prefab banner. Shown in ExplicitConsent and Default flows when ShouldShowBanner=true. Skipped in ImplicitConsent and Usa flows.
📱
iOS ATT Prompt iOS only
Native iOS App Tracking Transparency system dialog. Only if notDetermined and age gate granted tracker permission.
🔔
Push Primer If registered
Runtime plug-and-play step via BootflowRuntimeSteps. Shown after compliance sequence.

Spire Unity · VContainer

Entry point: LoadingScreen → PlatformSDK.RunBootflow() → bootflow.Run(cancellationTokenSource.Token) — up to 3 retries.

⚙️
Config: UseCombinedAgeGate: 1 and UseNativeOneTrustBanner: 1 are both enabled. Spire always shows the combined dialog, and uses the native OneTrust SDK banner instead of a custom Unity prefab. OneTrust domain IDs: iOS 019831da… · Android 019831d9…
Modal Sequence
🚫
Region Blocked Dialog Blocks game · GeoBlocked result
Container disposed on geo-block. Player cannot proceed.
📋
Combined AgeGate + ToS Dialog Always combined
Single screen: age slider + ToS + Privacy links. Uses SpireTosUrlProvider for Spire-specific URLs. Extra pt-BR localization via SpirePlatformLocalization.
🔞
Age Blocked AgeBlocked result
Container disposed. ConfirmWindowBuilder.CreateAgeBlockedWindow() shown.
🍪
Native OneTrust Banner EU / GDPR only
Native OneTrust SDK banner — not a custom Unity prefab. The only game using native OneTrust. Shown in ExplicitConsent regions.
📱
iOS ATT Prompt iOS only
After trackers permission granted by age gate. BootflowUIWatcher tracks analytics for both AgeGate and OneTrust UI open/close events.
🔔
Push Primer If registered
Runtime plug-and-play step. Shown later in FinishNetworkSetup.
🛒
Marketing / Tailored Offers Toggle Post-login · In-Settings
Not a bootflow modal — a post-login Settings preference. MarketingConsentToggleRow + TailoredOffersConsentResolver control tailored offer eligibility.
🧪
QA Note — Debug Geo Override: In DEBUG_MODE builds, QA can call SimulateOptInRegion (France/EU) or SimulateOptOutRegion (US) debug commands to simulate geo locations without a VPN. This exercises the EU consent banner flow on any device.

Atlas Unity · Microsoft.Extensions.DI

Entry point: AppManager → LoginState.Begin() → _bootflowSequence.Run(default) — up to 3 retries with 1s delay. Active codebase: proj-atlas-monorepo/krang (proj-atlas-krang is archived).

⚙️
Config: UseCombinedAgeGate: 1 and ShowPhotosensitivityWarning: 1 are both enabled — making Atlas the only game with a photosensitivity warning. USA is configured with AgeGateRule: NoAgeGate — US players see ToS only, no age slider.
Modal Sequence
⚡
Photosensitivity Warning Always · Atlas only
Shown before any compliance flow. No other Fortis game shows this. Configured via ShowPhotosensitivityWarning: 1 in PlatformBootflowConfiguration.asset.
🚫
Region Blocked Dialog Blocks game
GeoFencingStep check. Player cannot proceed if blocked.
📋
Combined AgeGate + ToS Dialog Always combined
Single screen. USA players skip the age slider (AgeGateRule: NoAgeGate) — only ToS acceptance is shown.
🔞
Age Blocked If underage
Bootflow result maps to AgeBlocked. Game halts.
🍪
OneTrust Consent Banner EU + Default flows
Custom Unity prefab (OneTrustBannerDialog). Shown in ExplicitConsent and Default flows. OneTrust SDK version 202601.2.5.
📱
iOS ATT Prompt iOS only
After trackers permission granted.
🔔
Push Primer If registered
Runtime plug-and-play step.
🎮
FTUE Bypass: If the tutorial raid is not completed, the entire login screen is skipped — the bootflow still runs (auth, age gate, ToS) but the player is dropped straight into the FTUE server. In RETAIL_BUILD, silent login always fires without showing a server-picker UI.

Mergemon TypeScript / React Web

Entry point: app/src/fortis/client.ts wraps createFortisSDK() → sdk.bootflow.run(). Uses the @fortis/sdk TypeScript web SDK — not the Unity Platform SDK.

🌐
Stack difference: Mergemon is a React web app with Capacitor for native iOS/Android. All compliance dialogs are custom vanilla DOM overlays (not Unity prefabs). The visual theme is a campfire-style dark UI with TosPopupBG.webp background.
Modal Sequence
🚫
Region Blocked Overlay Blocks game
Full-screen DOM overlay via app/src/fortis/geoFenceDialog.ts. Mergemon also has a custom complianceRules.json for additional release-gating per country (released: boolean), independent of geo-fencing.
📋
Combined AgeGate + ToS Card Always combined
Age slider (0–65+) + ToS + Privacy links in a single DOM card. Slider uses inertia/hysteresis logic for precise mobile dragging. Age value stored locally in localStorage. Legal docs load in an in-app text modal (web: /api/legal/* proxy; native: CapacitorHttp).
🔞
Age Restricted Overlay If underage — 2hr TTL
Shows "RESTRICTED" overlay. Underage age entry is cached locally and expires after 2 hours — then the player is re-prompted. If canPlay=true, cache persists indefinitely.
🔄
ToS Update Card (returning players) If agreements updated
Returning player flow — age pre-filled from localStorage, slider locked. Player re-accepts updated ToS.
🍪
OneTrust Consent Banner GDPR + USA flows
Web OneTrust SDK banner. Shown in both GDPR and USA compliance flows (more than Unity games). Requires VITE_ONETRUST_DOMAIN_ID env var. Falls back to age-gate implicit consent if not configured.
📱
iOS ATT Prompt Native Capacitor iOS only
Only when the native Singular plugin (@fortis/capacitor-singular) is configured on a native Capacitor iOS build.
🛡️
Pre-OneTrust Stopgap: Mergemon has a "Do Not Sell or Share My Personal Information" toggle in Settings (trackingPreference.ts). When enabled, it suppresses Singular attribution/tracking. This is a local localStorage preference that will eventually be replaced by OneTrust's full consent management. Fortis auth, geo, age gate, and first-party analytics remain active regardless.

Regional Compliance Flows

The Platform SDK uses geo-IP to determine which compliance sequence to run. Each flow has a different modal order. The mapping is fetched from the Terra API (compliance/v1/bootflow) with a static fallback in ComplianceSequenceDescriptorScriptableMap.asset.
